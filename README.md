# fredericatlan.github.io

Page personnelle de **Frédéric Atlan** — Digital Engineering & Transformation.

## Local

Ouvrir `index.html` dans le navigateur, ou :

```bash
cd page-perso
python3 -m http.server 8080
```

Puis http://localhost:8080

## SEO (ordre Google → IA)

1. **Google** — `index.html` : title, meta description, `canonical`, H1/H2, texte indexable, JSON-LD Person/WebSite  
2. **Découverte** — `sitemap.xml` + `robots.txt` (Sitemap + Allow Googlebot)  
3. **IA** — `llms.txt` + Allow GPTBot / ClaudeBot / PerplexityBot dans `robots.txt`
