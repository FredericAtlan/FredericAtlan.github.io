CycleGen

Générer des cycles de roulage automobiles synthétiques physiquement réalistes — profils vitesse v(t) et pente α(t) — pour l’ingénierie amont (validation, études énergie, scénarios réalistes).

Objectif

Partir d’un trajet réel (ou d’un corridor géographique) pour produire des profils temporels exploitables en simulation véhicule : vitesse, altitude, contraintes routières, sans enregistrement terrain systématique.

Pipeline

  • Routage — Mapbox ou OSRM (géométrie du parcours)
  • Contexte route — Overpass (feux, ponts, tunnels, limitations)
  • Relief — élévation le long du tracé
  • Corridor — enveloppe de vitesse cohérente avec le réseau
  • Trafic — modèle IDM intégré ; SUMO / TraCI en option (Docker)
  • Export — CSV et XML pour chaînes d’outils d’ingénierie

Stack

  • API — FastAPI (Python) : calculs, orchestration du pipeline, endpoints stables
  • Frontend — Next.js (TypeScript) : carte, paramètres, visualisation ; déployable en statique (GitHub Pages) ou en local
  • Simulation — IDM natif ; couche SUMO optionnelle pour scénarios microscopiques

Le front Next.js et l’API FastAPI sont deux composants distincts : le front consomme l’API via une URL configurable (NEXT_PUBLIC_API_URL).

Installation & déploiement

  • Local — cloner le dépôt, lancer l’API FastAPI et le front Next.js selon le README
  • Hébergé — UI statique (ex. GitHub Pages) pointant vers une API FastAPI déjà exposée (Render, Railway, etc.)
  • SUMO — conteneur Docker documenté dans le repo pour activer TraCI
